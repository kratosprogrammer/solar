# 🌌 شبیه‌ساز سه‌بعدی و تعاملی منظومه شمسی (Persian Solar System 3D)

یک اپلیکیشن وب بسیار مدرن، روان و سینمایی برای کاوش در منظومه شمسی به زبان فارسی. این پروژه با بهره‌گیری از تکنولوژی‌های روز وب ۳بعدی (WebGL/Three.js) طوری طراحی شده است که کاربران بتوانند سیارات، مدارها، کاوشگرهای فضایی و مقایسه مقیاس‌های کیهانی را با بالاترین کیفیت تجسم کنند.

---

## ✨ ویژگی‌های برجسته پروژه

* **🪐 شبیه‌سازی دقیق ۳بعدی:** رندر سیارات با تکسچرهای 2K بسیار باکیفیت و بهینه‌شده، همراه با هاله جوی (Atmosphere Shaders)، شیدر اختصاصی حلقه‌های زحل و غبار کیهانی.
* **🛸 کنترل سفینه فضایی سینمایی:** امکان هدایت سفینه فضایی در منظومه شمسی، سفر نرم و هوشمند به سمت سیارات و پهلوگرفتن خودکار (Docking) روی بخش روشن (Sunlit Face) سیارات.
* **🛰️ مسیر و موقعیت کاوشگرهای تاریخی:** ردیابی خطوط مداری و اطلاعات کامل کاوشگرهای معروف فضا مانند Voyager 1، Voyager 2، Pioneer 10، New Horizons، Parker Solar Probe و تلکسوپ‌های فضایی وب و هابل.
* **📊 سیستم مقایسه مقیاس سیارات:** مشاهده و مقایسه همزمان اندازه سیارات و خورشید در کنار یکدیگر بر اساس داده‌های دقیق اخترشناسی NASA، منطبق بر استانداردهای فارسی (RTL).
* **⏱️ کنترل‌کننده زمان و سرعت مدارها:** امکان متوقف کردن زمان، مشاهده حرکت واقعی، و شبیه‌سازی سرعت مدارها به صورت ۱ روز یا ۱ ماه در ثانیه.
* **📷 حالت دوربین آزاد (Free Camera Mode):** چرخش و جابه‌جایی ۳۶۰ درجه و بی‌محدودیت در پهنه منظومه شمسی با کنترل‌های نرم و پاسخگو.
* **⚡ بهینه‌سازی فوق‌العاده (Instant Loading):** فشرده‌سازی ۹۵.۶ درصدی تکسچرها و لود آنی زیر ۱.۵ ثانیه حتی روی اینترنت‌های کند یا موبایل.

---

## 🛠️ فناوری‌های استفاده شده

* **Core & UI:** React 18 / Vite / TailwindCSS
* **3D Graphics & WebGL:** Three.js / React Three Fiber (R3F) / @react-three/drei
* **State Management:** Zustand
* **Animations:** GSAP (GreenSock Animation Platform)
* **Post-processing & Shaders:** @react-three/postprocessing (Bloom & Vignette) / GLSL Custom Shaders

## 🚀 راهنمای راه اندازی و اجرا روی سیستم شما

برای اجرای پروژه روی سیستم شخصی خود، مراحل زیر را دنبال کنید:

### ۱. کلون کردن مخزن (Clone)
```bash
git clone https://github.com/kratosprogrammer/solar.git
cd solar
```

### ۲. نصب پکیج‌ها (Dependencies)
```bash
npm install
```

### ۳. اجرای سرور توسعه (Dev Server)
```bash
npm run dev
```
پس از اجرای دستور فوق، آدرس `http://localhost:5173` را در مرورگر باز کنید.

### ۴. بیلد گرفتن برای نسخه نهایی (Production Build)
```bash
npm run build
```

## 🌌 ساختار پروژه

```text
solar/
├── public/
│   └── assets/
│       ├── models/        # مدلهای 3D (سفینه فضایی GLB)
│       └── textures/      # تکسچرهای 2K بهینه‌شده سیارات و فضا
├── src/
│   ├── components/
│   │   ├── canvas/        # کامپوننت‌های 3D (Planet, Sun, Spaceship, Camera, ...)
│   │   └── ui/            # کامپوننت‌های رابط کاربری (Sidebar, Modals, TimeController, ...)
│   ├── config/            # داده‌های اخترشناسی و علمی سیارات (planetsData.js)
│   ├── state/             # مدیریت استیت سفینه (shipState.js)
│   ├── store/             # استیت عمومی برنامه با Zustand (useSolarStore.js)
│   ├── App.jsx            # ریشه برنامه و کنترل‌کننده لودینگ
│   └── main.jsx           # نقطه ورود React
├── package.json
└── vite.config.js
```
